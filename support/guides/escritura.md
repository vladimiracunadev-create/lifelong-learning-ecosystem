# Escribir un argumento comprensible

**ID:** `SUP-WRITE` · **Estado:** guía inicial; propuesta editorial pendiente de revisión pedagógica humana.

## Situación y destinatario

Preparar una propuesta breve para que un grupo organice una sesión de intercambio de libros. Todo el caso es ficticio. Datos disponibles: seis personas manifestaron interés en intercambiar libros y declararon tener libros para compartir; existe una sala para doce personas; todavía no se conoce la disponibilidad de horario.

## Secuencia

1. Formular el propósito: “Quiero que el grupo acuerde una sesión de prueba y elija un horario”.
2. Escribir una afirmación: “Propongo una sesión de intercambio de libros”. Añadir evidencia: “Seis integrantes manifestaron interés y contamos con una sala para doce personas”.
3. Reconocer un límite: “Falta confirmar el horario y cuántas personas asistirían”.
4. Añadir una acción verificable: “Podemos consultar dos horarios y confirmar la sesión cuando tengamos respuestas”.
5. Integrar las frases en un párrafo y leerlo como destinatario. Subrayar la propuesta, las razones y el paso siguiente.

**Ejemplo trabajado:** “Propongo una sesión de intercambio de libros. Seis integrantes manifestaron interés y disponemos de una sala para doce personas. Aún debemos confirmar el horario y la asistencia. Sugiero consultar dos horarios y decidir después de revisar las respuestas”.

## Revisión concreta

Comparar con esta frase: “Todos quieren intercambiar libros, así que hagámoslo mañana”. Indicar dos problemas: “todos” no está sustentado y “mañana” no fue acordado. Revisar sin añadir hechos nuevos.

Pedir a otra persona que responda qué se propone y qué falta decidir. Si no coincide con la intención, ajustar el texto. La evidencia de aprendizaje son el borrador, la versión revisada y las razones de los cambios; la opinión general de que “suena mejor” no basta por sí sola.

## Alternativas y transferencia

Se puede dictar, grabar una explicación breve o usar un organizador con tres tarjetas: propuesta, razones, siguiente paso. Después producir el formato requerido con apoyo. Transferir a una solicitud de uso de una sala o a la explicación de una decisión de proyecto, conservando exactitud y adecuación al destinatario.

## Comprobación y continuidad

- El lector puede identificar la propuesta y sus razones.
- Los datos ficticios se distinguen de opiniones o supuestos.
- La revisión mejora una dificultad concreta de claridad o coherencia.

Si falta una evidencia, repetir una variante acotada o adaptar el apoyo. Estos criterios describen el producto observado; no establecen un diagnóstico ni un nivel permanente de la persona. Registrar el apoyo utilizado y volver a la malla cuando la base necesaria pueda demostrarse.
