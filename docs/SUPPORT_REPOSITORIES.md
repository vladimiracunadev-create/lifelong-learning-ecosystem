# Repositorios y recursos de apoyo

## Función

Un apoyo resuelve una necesidad concreta de una trayectoria: comprender una consigna, recuperar una base matemática, producir una evidencia, utilizar una herramienta o revisar una fuente.

Los diez apoyos iniciales están desarrollados en [support](../support/README.md). Cada uno indica una señal de necesidad, actividades, criterios de éxito y conexiones candidatas con programas.

## Reutilizar antes de separar

1. Revisar si existe un recurso pertinente dentro del programa principal.
2. Consultar el catálogo de programas y laboratorios.
3. Verificar nivel, propósito, requisitos y estado.
4. Añadir una referencia o actividad puente cuando resuelva la necesidad.
5. Proponer un repositorio nuevo solo si hay una responsabilidad propia y mantenible.

Un tema compartido no implica duplicar capítulos. El maestro puede explicar cuándo elegir un tratamiento general o uno especializado.

## Familias de apoyo

| Familia | Uso |
| --- | --- |
| Lectura y escritura | Comprender instrucciones, argumentar y redactar para un propósito |
| Matemática | Recuperar bases cuantitativas necesarias para una tarea |
| Aprender a aprender | Definir metas, practicar, revisar y ajustar |
| Idiomas | Comprender fuentes y comunicarse en el contexto necesario |
| Investigación | Buscar, contrastar y documentar evidencia |
| Accesibilidad | Reducir barreras de formato, participación y demostración |
| Laboratorios | Aplicar conocimientos en una situación controlada |
| Portafolio | Organizar evidencias y decisiones de progreso |
| Herramientas e IA | Facilitar tareas con fuentes y límites visibles |

## Aplicaciones y laboratorios

Una aplicación puede servir como objeto de práctica. Su condición de software operativo no la convierte por sí sola en programa educativo.

La integración debe aportar objetivo, preparación, tarea, entorno, evidencia, revisión y cierre. Un laboratorio avanzado necesita requisitos y recursos acordes; su incorporación a una ruta escolar requiere adaptación específica.

## Criterios para crear un repositorio nuevo

Debe existir:
- Una necesidad recurrente que los recursos actuales no resuelven.
- Un público y objetivo claros.
- Contenido o funcionalidad inicial utilizable.
- Una relación precisa con el maestro.
- Una persona o proceso capaz de mantenerlo.
- Criterios de calidad y condiciones de reutilización.

El nombre se elige después de verificar la cobertura existente y su alcance. Los nombres nuevos son propuestas hasta que el repositorio se cree y se identifique.

## Incorporaciones pendientes

Los programas de derecho, psicología y libros necesitan identidad actual verificable. La continuidad infantil requiere inventario de experiencias dirigidas al niño. Estos pendientes están en [catalog/pending.json](../catalog/pending.json).

La siguiente revisión debe buscar también recursos de idiomas, artes, lectura especializada, investigación y habilidades de la vida cotidiana que el usuario ya pueda tener, sin asumir su inexistencia.
