# Modelo pedagógico del maestro

## Del propósito a la evidencia

El diseño parte de una situación de aprendizaje y un resultado que la persona pueda demostrar. Desde ese resultado se eligen conocimientos, actividades, apoyos y criterios. Esta es una decisión de diseño del proyecto, que debe revisarse mediante uso y evidencia.

Una actividad debe responder: qué se hará, con qué información, qué decisiones requiere, qué evidencia se conservará, cómo se revisará y qué continuidad abre.

## Tres ejes simultáneos

La etapa vital define condiciones de acompañamiento y ejemplos. El dominio de una competencia se describe con evidencias. El propósito explica por qué conviene estudiar determinados contenidos.

Un mismo recorrido puede adaptarse para una persona con experiencia laboral y para alguien que inicia una especialidad. La adaptación cambia los ejemplos y el apoyo; los resultados esperados se hacen explícitos en cada caso.

## Seis niveles descriptivos

| Nivel | Pregunta de diseño |
| --- | --- |
| Exploración | ¿Puede observar, preguntar y ensayar con acompañamiento? |
| Fundamentos | ¿Puede explicar relaciones básicas y reconocer ejemplos? |
| Aplicación acompañada | ¿Puede realizar una tarea con orientación y reconocer errores? |
| Autonomía | ¿Puede resolver una tarea pertinente y justificar sus decisiones? |
| Profundización | ¿Puede comparar alternativas y trabajar con condiciones nuevas o ambiguas? |
| Creación e investigación | ¿Puede formular y revisar una contribución propia con evidencia? |

Estos niveles son una convención editorial. Cada competencia contiene descriptores específicos. No se presume que una persona tenga un único nivel global ni que todos los aprendizajes deban culminar en investigación.

## Prerrequisitos

Un prerrequisito se incorpora cuando la actividad realmente necesita un conocimiento anterior. Debe existir una explicación educativa y una forma de demostrarlo. Las preferencias de orden se documentan como recomendaciones.

El campo `prerequisites` del catálogo inicial orienta relaciones de progresión. Como no expresa un nivel mínimo por tarea, no puede bloquear automáticamente la exploración. La malla define el requisito real de ingreso: observar y dibujar un lugar no exige calcular porcentajes; una tarea posterior con escalas o comparaciones porcentuales puede requerirlos.

Los grafos de prerrequisitos no contienen ciclos que impidan el ingreso. Los ciclos de práctica, retroalimentación y retorno a una ruta sí forman parte del aprendizaje.

## Reconocer experiencia

La persona puede presentar un producto, una explicación o una demostración breve. El formador acuerda la evidencia pertinente antes de evaluar. La experiencia declarada orienta la conversación y no se convierte automáticamente en dominio.

Una evidencia puede cubrir más de una competencia si se explica qué aspecto demuestra de cada una. También puede resultar parcial. Se conservan decisiones y criterios para permitir revisión.

## Práctica y transferencia

Las actividades puente proponen datos ficticios, preguntas y productos concretos. Se recomienda variar una condición al revisar el trabajo para observar si la persona comprende la decisión o solo reproduce una respuesta.

Transferir no significa aplicar sin límites: el estudiante explica qué condiciones cambian, qué conocimientos siguen siendo útiles y qué necesita investigar.

## Evidencia y retroalimentación

El repositorio distingue exposición al material, realización de una actividad y demostración de un resultado. Las rúbricas se utilizan para describir fortalezas, aspectos pendientes y una acción de mejora.

La devolución conecta un criterio, una observación y un próximo intento. La escala 0–3 organiza descriptores editoriales; no constituye una escala clínica ni una certificación profesional.

## Accesibilidad

Antes de atribuir una dificultad al conocimiento, se revisa si las instrucciones, el formato, el idioma, el acceso a herramientas o las condiciones de participación introducen una barrera.

Se pueden ofrecer respuestas orales, escritas, visuales o prácticas cuando conserven el objeto evaluado. Si el objetivo es escritura argumentativa, una respuesta oral puede apoyar el proceso pero no demuestra por sí sola todas las capacidades de escritura.

## Primera infancia

Las experiencias dirigidas al niño requieren acompañamiento, lenguaje, materiales y expectativas apropiados. El programa de pedagogía es una fuente para el adulto que diseña o acompaña, y no una secuencia que se traslada directamente al niño.

La primera entrega aporta orientaciones y experiencias de juego. Su continuidad como malla infantil completa requiere inventario y revisión especializada. Véase [pathways](../pathways/README.md).

## Calidad y revisión

Se requieren tres tipos de revisión: coherencia estructural, pertinencia editorial y evidencia de uso. Un validador puede detectar IDs rotos o ciclos; no juzga si una explicación es suficiente o si una actividad ayuda a aprender.

Las fuentes externas se asocian con la afirmación que respaldan. El marco general de aprendizaje durante toda la vida se documenta en [sources](../sources/README.md); las decisiones de esta propuesta se mantienen identificadas como propias.
