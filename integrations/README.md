## Estado de esta versión

Hay catorce fichas elaboradas a partir de README. Contienen un papel propuesto, límites, puntos de entrada observados, criterios para elegir unidades, objetivos candidatos, dependencias y una actividad puente original. No son catorce integraciones automáticas de todos los contenidos.

Los enlaces de destino no se abrieron salvo donde lo indique el catálogo. Ninguna correspondencia de competencia equivale por sí sola a revisión pedagógica o a reconocimiento académico oficial.

## Procedimiento compartido

Leer [UNIT_SELECTION.md](UNIT_SELECTION.md) para pasar de una referencia a una unidad seleccionada y revisada. El [contrato de datos](../docs/DATA_CONTRACT.md) describe los registros canónicos. El estado de desarrollo externo debe permanecer separado del estado de una actividad original del maestro.

## Evitar duplicaciones

Una base común puede aparecer en muchas rutas por referencia. Si una disciplina necesita otra aplicación, añadir una actividad de transferencia con su objetivo y evidencia. No copiar una clase completa para cambiarle el título, ni exigir que todos los programas adopten una estructura de carpetas idéntica.

## Gestionar cambios

Un cambio de nombre conserva el ID del maestro y registra la nueva ubicación. Una revisión del objetivo o evaluación exige comprobar las mallas que lo usan. El SHA de un README solo registra el contenido de ese archivo; una selección de clase necesita su propia evidencia de versión.
