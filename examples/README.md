# Ejemplos de uso

Todos los ejemplos son ficticios. Ayudan a comprender el ingreso a una malla y la relación entre conocimientos previos, apoyos y evidencia.

- [Tres perfiles y sus decisiones](FICTIONAL_PROFILES.md).
- [Portafolio de ejemplo](PORTFOLIO_EXAMPLE.md).

Para iniciar una copia propia, exporta una malla a una carpeta privada:

~~~bash
python scripts/export_plan.py --route M-03 --output exports/mi-plan.md
~~~

La exportación no modifica tus registros canónicos ni reconoce automáticamente competencias.
