# Tres perfiles ficticios

## Caso A — Camila explora una especialidad

Camila está terminando la educación media y le interesa diseñar espacios de lectura. Tiene experiencia en exposiciones escolares y necesita practicar proporciones y presupuestos.

**Ruta candidata:** M-01, seguida de M-04 si desea desarrollar un proyecto integrador.

**Decisión de ingreso:** revisar una explicación de un texto y una tarea con medidas. La edad y el curso ayudan a elegir ejemplos, pero no sustituyen las evidencias.

**Apoyos:** SUP-MATH para cantidades y proporciones; SUP-RESEARCH para documentar observaciones.

**Producto:** propuesta de rincón lector con plano sencillo, costos ficticios, criterios de selección y revisión de una alternativa.

**Continuidad:** si el interés se sostiene, seleccionar unidades concretas del programa de arquitectura después de revisar sus requisitos.

## Caso B — Andrés cambia de especialidad

Andrés tiene experiencia organizando operaciones y desea ingresar al desarrollo de software. Puede explicar necesidades de usuarios, pero su experiencia programando es limitada.

**Ruta candidata:** M-02.

**Decisión de ingreso:** presenta una especificación de un problema real recreado con datos ficticios. Se revisa qué demuestra de requisitos y qué no demuestra de programación o pruebas.

**Apoyos:** SUP-LAB para preparar un entorno pequeño y SUP-STUDY para organizar intentos y registro de errores.

**Producto:** catálogo de préstamos con reglas, ejemplos de entradas, comprobación y explicación de decisiones.

**Continuidad:** profundizar una especialidad o usar M-03 si el objetivo siguiente es una reconversión profesional más amplia.

## Caso C — Rosa aprende y comparte

Rosa está jubilada y quiere investigar la historia de una plaza. Tiene experiencia contando historias y quiere mejorar la organización de fuentes y la presentación digital.

**Ruta candidata:** M-05.

**Decisión de ingreso:** revisar una narración, la identificación de una fuente y una demostración de la herramienta elegida. La jubilación no determina el nivel de investigación ni la dificultad del producto.

**Apoyos:** SUP-RESEARCH, SUP-PORTFOLIO y SUP-ACCESS según las condiciones del formato.

**Producto:** una pequeña muestra con fuentes, una representación del espacio y una actividad para compartir lo aprendido.

**Continuidad:** investigar otro lugar, acompañar un grupo o profundizar arquitectura, historia local y comunicación.

## Qué comparten los casos

El objetivo es explícito, la experiencia previa se revisa mediante evidencia y las necesidades de apoyo se relacionan con tareas concretas. Cada plan puede cambiar sin invalidar lo aprendido antes.
