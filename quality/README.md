Las comprobaciones técnicas y la revisión pedagógica responden preguntas diferentes. Los informes de esta carpeta describen el alcance real y se actualizan cuando cambian datos, herramientas o contenido.

## Capas de calidad

| Capa | Qué comprueba |
| --- | --- |
| Estructura | JSON legible, campos, IDs y tipos |
| Integridad | Referencias, rutas, enlaces internos y ausencia de ciclos de prerrequisitos |
| Derivados | Lector generado a partir de los archivos actuales |
| Editorial | Actividades claras, propósito, evidencia y continuidad |
| Especializada | Pertinencia disciplinar, progresión y condiciones de uso |
| Uso | Observaciones y resultados en un contexto definido |

Las dos últimas capas requieren trabajo posterior. Un informe técnico correcto no otorga validación psicométrica ni eficacia pedagógica.
