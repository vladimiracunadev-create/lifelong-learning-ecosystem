# Evaluación inicial: encontrar un punto de entrada

La evaluación inicial sirve para diseñar el siguiente recorrido con una persona. Esta propuesta editorial utiliza tareas breves y conversación; necesita revisión humana según el contexto. No clasifica a la persona en un único nivel ni prescribe una edad de ingreso.

## Antes de la tarea

Acordar la meta, las condiciones de participación y qué se hará con la evidencia. Preguntar por experiencias relacionadas y apoyos útiles sin exigir diagnósticos personales. Elegir una o dos competencias decisivas para el próximo paso: revisar todo el catálogo de una vez añadiría una carga que puede no aportar información pertinente.

## Caso completo: crear una planilla para un proyecto

**Meta ficticia:** comparar costos de una actividad de intercambio de libros.

**Competencias de entrada:** C-NUM-02 y C-DIG-01. Se añade C-RES-01 cuando se necesiten costos externos actuales; la primera tarea usa datos ficticios y no requiere buscar precios reales.

**Tarea 1:** interpretar un caso con 20 unidades de material, un aumento de 25% y posterior uso de 20% del total. Pedir cálculo y explicación de bases; el resultado es 20 unidades disponibles.

**Tarea 2:** guardar el cálculo como archivo de prueba, localizarlo y exportar una copia legible. Si la herramienta impide participar, aceptar papel u otra forma accesible para observar primero el razonamiento y preparar después un apoyo digital separado.

**Tarea 3:** explicar qué cambiaría si el segundo porcentaje fuera 10%; el resultado sería 22,5 unidades si el material permite fracciones. Si se trata de objetos indivisibles, señalar que debe precisarse la regla del caso. La observación de esta restricción es evidencia útil de comprensión.

## Cómo registrar la decisión

Ejemplo: “Identifica ambas bases y verifica el cálculo. Guarda el archivo con acompañamiento, pero no logra localizar la copia. Propuesta: iniciar el contenido de presupuesto y realizar en paralelo una práctica de organización de archivos. Revisar localización y exportación en el próximo producto”.

El registro separa competencias: no obliga a repetir matemáticas por una dificultad digital. Si la persona identifica la base solo después de una pista de contenido, registrar la pista y realizar una variante para observar qué puede explicar después.

## Posibles resultados

- **Entrada directa al paso:** la evidencia cubre sus requisitos dentro del contexto descrito.
- **Entrada con apoyo paralelo:** una base puede desarrollarse sin bloquear la actividad principal.
- **Puente previo:** falta una relación necesaria para comprender la siguiente tarea.
- **Información pendiente:** la tarea no permitió observar el resultado o existe una barrera que debe resolverse primero.

Estas opciones son decisiones de diseño revisables, no categorías permanentes del estudiante.

## Adaptación por contexto

Para infancia, usar juego, conversación y materiales apropiados con acompañamiento. Para una persona con experiencia, empezar por productos o problemas reales que desee explicar. Para adultos que retoman estudio, evitar repetir rutas completas por defecto: comprobar los requisitos concretos. No atribuir a un programa de pedagogía la función de actividad infantil; el formador prepara y revisa la experiencia correspondiente.
